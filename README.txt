Bộ website profile doanh nghiệp cho CÔNG TY TNHH CÔNG NGHỆ DARKTECH.

- index.html
- style.css
- script.js

Cách cập nhật:
1. Giải nén ZIP.
2. Vào GitHub repo đang kết nối Cloudflare Pages.
3. Upload đè 3 file: index.html, style.css, script.js.
4. Commit changes.
5. Chờ Cloudflare Pages tự deploy.
